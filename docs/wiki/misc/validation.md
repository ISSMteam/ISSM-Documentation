# Validation Guide
Linked here is the [validation guide for ISSM](https://issm.jpl.nasa.gov/validation/validation.pdf){:target="_blank"}. Several experiments using [EISMINT (European Ice Sheet Modelling INiTiative)](https://uia.org/s/or/en/1100064309){:target="_blank"} and [ISMIP-HOM (Ice Sheet Model Intercomparison Project for Higher-Order ice sheet Models)](https://frank.pattyn.web.ulb.be/ismip/welcome.html){:target="_blank"} have been run to validate the code. The results are compared with other existing software models.
