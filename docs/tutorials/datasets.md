# Datasets
To run the tutorials, you will need to download a number of datasets. The easiest way to do this is to run,
````
${ISSM_DIR}/scripts/DownloadExamplesDatasets.sh
````
The default behavior of this script is to download the datasets to the `../examples/Data` directory relative to the location of the script. If you wish to download them to another location, supply the optional path argument.

If you would prefer to download the datasets manually, use the following links, downloading each file to `${ISSM_DIR}/examples/Data`:

<div data-marker="datasets-list-start"></div>
- [Square ice shelf dataset](https://issm.jpl.nasa.gov/files/workshop2014/SquareShelf.nc){:target="_blank"}
- [SeaRISE Antarctica v0.75](https://issm.jpl.nasa.gov/files/examples/Antarctica_5km_withshelves_v0.75.nc){:target="_blank"}
- [SeaRISE Greenland dev1.2](https://issm.jpl.nasa.gov/files/examples/Greenland_5km_dev1.2.nc){:target="_blank"}
- [MEaSUREs Antarctic velocities](https://issm.ess.uci.edu/files/tutorials/Antarctica_ice_velocity.nc){:target="_blank"}
- [MEaSUREs Greenland velocities (vx, NSIDC-0670)](https://issm.ess.uci.edu/files/tutorials/greenland_vel_mosaic250_vx_v1.tif){:target="_blank"}
- [MEaSUREs Greenland velocities (vy, NSIDC-0670)](https://issm.ess.uci.edu/files/tutorials/greenland_vel_mosaic250_vy_v1.tif){:target="_blank"}
- [Pine Island ice thickness cross overs (Dakota)](https://issm.jpl.nasa.gov/files/workshop2014/CrossOvers2009.mat){:target="_blank"}
- [Jason Box's SMB data](https://issm.jpl.nasa.gov/files/examples/Box_Greenland_SMB_monthly_1840-2012_5km_cal_ver20141007.nc){:target="_blank"}
- [Jakobshavn Isbr&#230; bed map](https://data.cresis.ku.edu/data/grids/old_versions/Jakobshavn_2008_2011_Composite.zip){:target="_blank"}  (we only need `grids/Jakobshavn_2008_2011_Composite_XYZGrid.txt`)
- [GRACE and supporting datasets for SESAW tutorials](https://issm.jpl.nasa.gov/files/examples/GRACE_and_suporting_datasets.zip){:target="_blank"}
